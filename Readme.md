# 8 Steps Sequencer
This Repo containes a simple 8 Step sequencer for the Eurorack Modular standard. 

## Features
- 8 channels where each one has a Gate output
- one combined output that outputs the CV indicated by the potis of each channel
- one comnined gate output
- one LFO to set the sequencer speed

### Extra
- Rotary encoder to only loop from 0 - selected channel
